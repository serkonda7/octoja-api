createAgentClient(options)

Isolated hey-api instance (no shared client singleton, so technician tokens cannot leak into agent requests).

interface CreateAgentClientOptions {
/**
	 * Base URL of the Octoja instance, e.g. `https://acme.eu1.octoja.cloud`.
	 */
	baseUrl: string
	/**
	 * Access token, sent as `Authorization: Bearer <token>`. Optional so a
	 * client can be created first and authenticated later via `auth.login`
	 * or `setToken`.
	 */
	token?: string
	/**
	 * Custom fetch implementation. Defaults to `globalThis.fetch`.
	 */
	fetch?: typeof fetch
	/**
	 * Extra hey-api client config merged over the defaults.
	 */
	config?: Omit<Config, 'baseUrl' | 'auth' | 'fetch'>
}

OctojaApiError

Thrown on any non-2xx response. Fields: message, status?, body, request?, response?. Catch with error instanceof OctojaApiError.
